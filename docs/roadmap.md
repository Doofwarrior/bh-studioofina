# BH Studio Roadmap

## v1.0.0 (Current — Locked)

**Status:** In implementation. No structural changes permitted.

**Scope:**
- Project CRUD and dashboard
- Workspace management
- AI Bridge with single provider
- 3 core skills: referenceIntelligence, exportIntelligence, decisionArchive
- 1 Islamic skill: visualDirector
- Prompt library
- Export system
- Backup system

**Implementation Order:**
1. Scaffold repository
2. Build storage/workspace layer
3. Implement AI Bridge
4. Implement 3 core skills
5. Build project workflow
6. Add islamic.visualDirector
7. Polish and ship

## v1.1 (Future — QoL Only)

**Policy:** UI polish, performance, documentation, minor UX. No architecture changes.

**Candidates:**
- Dark mode refinement
- Keyboard shortcuts
- Search across projects
- Drag-and-drop file import

## v2.0 (Future — New Capabilities)

**Policy:** Requires architectural additions. Must have standalone blueprint.

**Candidates:**
- Additional AI skills (see v2.0 Ideas document)
- Testing framework
- Plugin system for export formats
- Collaboration features
- Multi-provider AI support

## Change Control

All proposals for v1.1 and v2.0 must:
1. Be written as standalone proposals
2. Be reviewed against the 9 Philosophy Lock principles
3. Be approved explicitly
4. Be logged in changelog.md
